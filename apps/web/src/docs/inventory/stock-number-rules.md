Stock number is how StarterGrid finds a vehicle when you import or edit. Keep it the same while that unit is on the lot.

## What to do

- Use the same stock number the whole time the vehicle is here.
- Use a different stock number for a different vehicle, including when the old vehicle is sold or removed.
- Match your dealership management system (DMS) stock number when it uniquely identifies the same vehicle.

## After a unit leaves

Mark the old unit sold or removed and keep its stock number attached to that record. Spreadsheet imports match existing records by dealership and stock number, including old inventory. Closing out the old vehicle does not free its stock number for a new one. Review any row labeled as an update before importing.
