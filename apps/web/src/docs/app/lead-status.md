On Leads, mark each inquiry **New**, **Contacted**, **Appointment**, **Closed / Won**, or **Lost**. Your team sees the same status. Buyers never see it. It does not change listings.

## When to use each one

| Status | Use it when |
| --- | --- |
| New | Nobody has followed up yet |
| Contacted | You reached the buyer |
| Appointment | A visit or call is booked |
| Closed / Won | The deal is done |
| Lost | The buyer went elsewhere or stopped answering |

## What happens next

A new inquiry starts as **New**. Change it when you take the next step. The rest of the team sees that change in this inbox.

The inbox and delivery results are separate. Open **Leads → Delivery log** to review recorded notifications. Configure alerts in **Settings → How you hear about new inquiries**. An inquiry appearing in the inbox does not confirm an email was delivered.

## Send an inquiry to your CRM

A customer relationship management system (CRM) is separate from the shared inbox. Use the inquiry’s **Send to CRM** action to review its destination and delivery result. Acceptance by the mail server does not confirm that the CRM imported the inquiry. If sending is unavailable, read the reason and use the copy or export options shown. Changing a lead status does not send it to the CRM.
