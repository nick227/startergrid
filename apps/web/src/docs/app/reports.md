Open **Reports** from the dealership header. Choose the report that matches the question you are trying to answer, then check the dealership and date range.

## Before acting on a number

- Check when the data was last updated.
- Read the labels: inventory totals, sent updates and confirmed live listings measure different things.
- An empty report may mean there are no matching records or the data is not available. It does not prove there were no problems.
- Use the relevant vehicle, lead or destination page to make changes.

For a listing problem, start with [Why a website has not updated](doc:app/sync-vs-accounts). For price suggestions based on time in stock, read [Review older inventory](doc:inventory/older-inventory).
